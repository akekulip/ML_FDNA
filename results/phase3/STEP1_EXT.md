# Phase 3 — extension diagnostics (exact, no training; agents + independent reproduction this session)

All numbers below were independently reproduced in this session (not taken on an agent's word); scripts and tests committed.

1. **LODF compensation determinant (src/fdna/lodf.py, tests/test_lodf.py).** Det(a,b) = 1 - LODF(a,b)*LODF(b,a), computed once per topology from a single Laplacian factorisation, no LP solve. Det=0 (machine precision) exactly recovers the 26 "new 2-cut" pairs (neither branch alone islands) found by connected-components; the correspondence does NOT hold for the 117 pairs where one member is already a single-line bridge (LODF is built on the base connected topology, so it is the wrong tool there — a genuine scope limit, not a bug).
2. **Risk correlation (scripts/p3_step1_lodf_corr.py), reproduced: Spearman rho=0.945** between 1/|Det(a,b)| and the measured flow-addition error (results/phase3/step1_flowadd.json's underlying 6,770 rows). Flagging the top 10% by this risk score captures 82% of the p95-error tail while touching ~10.1% of non-2-cut pairs (80/794; corrected from an earlier arithmetic error that reported 8.4% -- recomputed directly this session). This is a free (O(1) after one factorisation) trigger for switching from naive flow addition to an exact recompute.
3. **Structural floor (struct_mw, no linprog call).** For pairs whose gen-less island forms only jointly (neither single outage alone islands), struct_mw(a,b) is an exact, free lower bound on shed while struct_mw(a)=struct_mw(b)=0 — a near-tautological source of superadditivity for a subset of the 58 gen-less-only pairs (agent estimate: ~20/820, median 3.85% of demand; not independently re-verified this session, flagged for confirmation before use in a paper claim).
4. **Convexity / Jensen mechanism (CORRECTED, Phase 4 section 4.1).** y(c) is convex, non-increasing, piecewise-linear in the control vector c for fixed (op, outage): c enters the LP only through variable bounds (ramp_frac*pmax*c), each expressed as its own affine cap in ScenarioLP._bounds; convexity follows from LP duality/parametric-programming theory, not from data. **The original check computed V(round(E[C])) (nearest of 1024 discrete CV rows) instead of the true V(E[C]); this has been fixed** (scripts/p3_step1_jensen.py now calls ScenarioLP.y(c_bar) directly at the continuous posterior mean, no solver failures in 7,400 evaluations). Corrected exact gap E_post[y(c)] - y(E_post[c]): P1 mean 0.00462 (median 0.0014, 98.2% of 4,000 rows non-negative), P2 mean 0.00325 (median 0.0005, 93.4% of 3,400 rows non-negative) -- direction still matches the pre-stated prediction (P1 > P2, wider posterior spread), but the non-negative fraction is NOT 100%: the small negative values found (min about -2.5e-6) are at the scale of HiGHS solver tolerance, not a violation of the convexity argument, and are reported rather than rounded away.
   **Causal-attribution caveat (brief 4.1):** a positive Jensen gap does not by itself structurally cap A8/A9 at y(E[c]) -- A9 receives all 20 per-generator probabilities plus raw observations, and a generic regressor could in principle learn a nonlinear response. The Jensen gap remains a *candidate* mechanism for the standing D_I2-vs-A8/A9 effect (+0.03-0.04), not a proven cause. **Not yet done:** the brief's discriminating test (compare an explicit plug-in exact-composition predictor against a learned-summary predictor fed the identical posterior features) -- planned for Stage 3/4, deferred behind the higher-priority recurrent-generalisation screen.
